
# Ejercicio 2 - Visualización de datos con Matplotlib

En este ejercicio se realizó una inspección y visualización inicial del conjunto de datos Automobile utilizando Pandas y Matplotlib.

Se realizaron:

- Carga del conjunto de datos.
- Gráfico de dispersión entre mpg y weight.
- Histograma de mpg.
- Diagramas de caja de cylinders y origin.
- Gráfico de barras según model_year y origin.
